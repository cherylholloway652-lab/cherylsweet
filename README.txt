CHERYL SWEET — NETLIFY PACKAGE

This is a static-site export prepared from the latest saved Cheryl Sweet page content and its five recovered original photographs.

DEPLOY
1. Extract this ZIP.
2. In Netlify, choose Add new site -> Deploy manually.
3. Drag the extracted folder (the folder containing index.html, netlify.toml, src/, and public/) into the Netlify deploy area.
4. After publishing, open Forms in the Netlify site dashboard. The form is named "order-enquiry". Submit one test enquiry to verify that notifications are configured.

The order form posts to Netlify Forms. Netlify must detect the form during deploy; if the form does not appear in the Forms dashboard, redeploy the folder and check that form detection is enabled.

This ZIP is a static-site recreation of the page. The AppDeploy-only React client/backend has been replaced with Netlify Forms so enquiries can be collected on Netlify. No video showcase is included.
